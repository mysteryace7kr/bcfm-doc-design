# 인쇄문서 디자인 시스템

## 0. `section.page` 한 장이 A4 한 장

**이 절이 이 스킬에서 가장 중요하다.**

**고정 쪽 문서다.** `<section class="page">` 하나가 A4 한 장이고, Claude Design
캔버스에도 그 한 장이 카드로 뜬다. 쪽을 나누는 것은 사람의 일이다.

```html
<doc-page size="a4" margin="0">
<section class="page">
 <div class="body"> … 본문 … </div>
  <div class="foot"><span>문서명</span><span>1 / 2</span></div>
</section>
<section class="page">
 <div class="body"> … 다음 쪽 … </div>
  <div class="foot"><span>문서명</span><span>2 / 2</span></div>
</section>
</doc-page>
```

**쪽 박스를 넘치는 내용은 잘린다**(`overflow:hidden`). 다음 쪽으로 흘러가지 않는다.
대신 잘린 자리가 화면에 바로 보이므로, 그때 `section.page` 를 하나 늘려 이어 붓는다.

쪽을 나눌 때 지킨다.

- **제목마다 쪽을 새로 시작하지 않는다.** `1.` `2.` `3.` 이 새 쪽에서 시작해야 할
  이유는 없다.
- **「이어서」·「(계속)」 같은 제목을 만들지 않는다.** 넘어가면 그냥 넘어간 것이다.
- **쪽을 일부러 비우지 않는다.** 채우고 넘어간다.
- 푸터 오른쪽은 `1 / N` 쪽 번호다. 쪽을 늘리면 N 을 함께 고친다.
- `break-before:page` 를 쓰지 않는다 — 쪽을 이미 손으로 나눴다.

> 2026-09-04 에 고정 쪽 → 2026-09-07 에 흐름 문서 → 2026-09-10 에 다시 고정 쪽으로
> 왔다. **쪽 방식을 바꾸는 변경은 반드시 사용자에게 먼저 묻는다** — 쪽 번호·화면 쪽
> 카드·A4 고정이 한 덩어리로 딸려오므로 작은 선택이 전면 뒤집기가 된다.

## 1. 서식은 하나다

| 컴포넌트 | 쓸 때 |
|---|---|
| `report.dc.html` | `○▶※⇨` 개조식 위계 + 요약밴드 + 번호 섹션 — 보고서·검토·개념설명·언론분석·기안·건의서·질의서·업무진행 보고 |

2026-09-10 에 `formal`(기안)·`brief`(업무진행) 을 폐기했다. 기안의 수신처·발신명의·
결재란처럼 서식에 없는 요소는 그 문서에서 만들어 넣는다.

## 2. 만들기

1. `components/report.dc.html` 을 복사한다.
2. **본문 텍스트만 교체한다.** `<helmet>` 안 `:root`·클래스 정의는 건드리지 않는다.
3. 불릿은 클래스로 찍는다 — `.o`(○) `.k`(가.나.다.) `.t`(▶) `.n`(※) `.r`(⇨) `.lead`(번호 문단).
4. 표는 라벨 열을 `<th>` 로, 수치 셀만 `class="num"` 으로 우측정렬한다.
5. `.foot` 의 문서명과 `1 / N` 을 바꾼다.
6. **한 쪽이 찰 만큼 붓고, 넘치면 `section.page` 를 하나 늘려 이어 붓는다.**
7. 분량이 헐거우면 **속성 패널의 본문크기·줄간을 한 눈금 낮춘다.**

확인은 세 가지로 한다.

```bash
~/.claude/skills/doc-design/sync/fit.sh    내문서.dc.html   # 채움 + 합격·불합격
~/.claude/skills/doc-design/sync/orphan.sh 내문서.dc.html   # 외톨이 줄
~/.claude/skills/doc-design/sync/topdf.sh  내문서.dc.html   # 확인용 PDF
```

불합격이면 슬라이더를 한 눈금 낮추고 다시 본다. 슬라이더는 단조롭지 않다 —
13.5px 보다 13px 이 나을 수 있으니 한 눈금씩 실제로 재본다.

## 3. 하지 말 것

- `@page` 규칙 직접 작성 — `doc-page.js` 가 고정 쪽에서 `size: 210mm 297mm` 를 직접 쓴다(`doc-page.js:559-565`)
- `<doc-page>` 의 `size="a4"` 를 지우거나 바꾸기 — 이 값이 **화면 카드 크기와 인쇄 용지를 동시에** 정한다. 지우면 Letter 로 떨어진다
- 푸터를 `slot="footer"` 로 옮기기 — 그건 흐름 문서용이고 고정 쪽과 혼용이 금지되어 있다
- `.page` 의 padding(19 / 20 / 14mm) 을 임의로 바꾸기 — 한 쪽 용량 표가 이 값에서 나온다
- `<style>` 맨 위의 `@property --body-fs` / `--body-lh` 블록 삭제 — 속성 패널 값이 전달되지 않는 경로에서 본문이 16px·줄간 normal 로 튀는 것을 막는다
- 본문크기·줄간을 코드로 고치기 — **속성 패널 슬라이더를 쓴다.** 코드로 고치려면 네 군데(`@property` 둘, 문서 끝 `data-props` 기본값, `renderVals` 의 `?? 14`)를 함께 고쳐야 하고, 하나만 놓치면 Claude Design 이 옛 값으로 되돌린다
- `&nbsp;` 로 줄바꿈 맞추기 — 원고 글자를 건드리지 않고 서식의 줄바꿈 규칙으로 잡는다
- 링크 외 유채색 추가
- `▢` 사용 — 글리프가 없어 `□` 로 폴백된다
- `position:fixed`·뷰포트 단위(`vh`/`vw`) — 인쇄에서 깨진다
- 색·크기 값을 인라인으로 새로 쓰기 — `var(--토큰)` 을 쓴다

## 4. 합격 기준

`fit.sh` 는 마지막에 **합격 / 불합격**을 찍는다. 이게 이 시스템의 기준이다.

| 항목 | 기준 | 왜 |
|---|---|---|
| 잘린 쪽 | **0** | 내용이 사라진다 |
| 마지막 쪽을 뺀 모든 쪽 | **채움률 92% 이상** | 헐거운 쪽을 남기지 않는다 |
| 마지막 쪽 | **기준 없음** | 꼬리는 남는 내용만큼만 찬다. 메우려고 말을 지어내지 않는다 |
| 본문 크기 | **13px 이상** | 인쇄해서 사람이 읽는다 |
| 본문 글자 | **그대로** | 조판이 내용을 바꾸면 안 된다 |
| 외톨이 줄 | **0** | 5절 참조 |

**합격이면 그대로 낸다.** 눈으로 다시 맞추지 않는다.

**불합격이면 도구가 더 할 수 있는 게 없다는 뜻이다.**

| 불합격 사유 | 할 일 |
|---|---|
| 넘쳐서 잘린다 | 쪽을 하나 늘려 이어 붓는다. 한 블록이 한 쪽보다 크면 그 표를 둘로 나눈다 |
| 92% 못 채운 쪽이 있다 | 그 자리에 나눌 수 없는 표·제목 덩어리가 걸렸다. **그 쪽만 사람이 본다** |
| 본문이 13px 미만 | 원고가 길다. 줄이거나 쪽수를 늘린다 — 글자를 더 줄이지 않는다 |

기준을 못 지킨 채로 "그럴듯해 보인다"고 넘기지 않는다. 그렇게 넘긴 문서가
8쪽 평균 74% 로 나왔다.

| 채움률 | 판정 |
|---|---|
| 100% 넘음 | 잘린다 |
| 92~100% | 적정 |
| 80~92% | 조금 빈다 |
| 80% 미만 | 비었다 |

목표는 **95% 안팎**이다. 마지막 쪽이 헐거운 건 정상이다 — 내용이 5.2쪽어치면
6쪽째는 20%밖에 안 찬다. 메우려고 없는 말을 지어내지 않는다.

**뼈대는 이 기준에서 뺀다.** `components/report.dc.html` 은 자리표시만 든
출발점이다(지금 93.9%). 기준은 원고를 부어 완성한 문서에 적용한다.

## 5. 줄바꿈 — 한 단어·한 글자를 외톨이로 남기지 않는다

한글 기본 줄바꿈은 글자 단위라 그냥 두면 어절 중간이 끊긴다(「판단된다」의 「고」만
다음 줄로 떨어지는 식). 서식이 세 가지를 함께 건다 — `word-break:keep-all`,
`text-wrap:pretty`, `hanging-punctuation:allow-end`. 제목은 `text-wrap:balance`.

`orphan.sh` 가 실제 렌더에서 검사한다. 두 줄 이상인 문단의 마지막 줄이 **한 글자면
불합격**, **한 단어 3글자 이하면 주의**다.

## 6. 산출

Claude Design 「인쇄문서」 프로젝트에서 편집하고 PDF 로 내보낸다.
용지는 `size="a4"` 가 정하므로 내보내기 대화상자에서 따로 고를 필요가 없다.

글꼴은 **Pretendard** 하나다. `local('Pretendard')` 가 먼저라 맥에 설치돼 있으면
그것을 쓰고, 없는 환경에서만 프로젝트 `fonts/Pretendard-*.ttf` 로 떨어진다.
측정 도구도 같은 설치본을 쓴다 — 내려받는 글꼴 캐시는 없앴다(2026-09-10).
**Pretendard Regular·Medium·Bold 가 `~/Library/Fonts` 에 있어야 측정이 돈다.**

어법·종결어미·문서 골격은 `doc-style` 스킬이 담당한다.
