# 인쇄문서 디자인 시스템

## 1. 아키타입 고르기

문서 종류가 아니라 **레이아웃 형태**로 고른다.

| 컴포넌트 | 쓸 때 |
|---|---|
| `report.dc.html` | 여러 장, `○▶※⇨` 개조식 위계 + 요약밴드 + 번호 섹션 — 보고서·검토·개념설명·언론분석 |
| `formal.dc.html` | 수신처·발신명의가 필요한 문서 — 기안(공문)·건의서·질의서·신청서. 결재란 포함 |
| `brief.dc.html` | 1~2쪽, 타임라인·항목 나열 — 업무진행사항·요약보고 |

애매하면 `report`.

## 2. 만들기

1. `components/`에서 해당 `.dc.html`을 복사한다.
2. **본문 텍스트만 교체한다.** `<helmet>` 안 `:root`·클래스 정의는 건드리지 않는다.
3. 불릿은 클래스로 찍는다 — `.o`(○) `.k`(가.나.다.) `.t`(▶) `.n`(※) `.r`(⇨) `.lead`(번호 문단).
4. `slot="footer"` 안 문서명·기관명을 바꾼다.
5. 표는 라벨 열을 `<th>`로, 수치 셀만 `class="num"`으로 우측정렬한다.

6. 분량이 한 쪽을 넘치면 **속성 패널의 본문크기·줄간을 먼저 낮춘다.** `formal`은 공문 관행상 기본이 13.5px/1.75로 더 촘촘하다. 그래도 안 되면 `<section class="page">`를 하나 더 만들어 나눈다.

7. 쪽을 늘릴 때는 `<section class="page">` 블록을 통째로 복사하고 푸터의 `n / N`만 고친다. **쪽수 제한은 없다.**

렌더 확인이 필요하면 `components/`에서 그대로 브라우저로 열면 된다 (`support.js`·`doc-page.js` 동봉).

## 3. 하지 말 것

- `@page` 규칙 직접 작성 — `doc-page.js`가 소유한다
- 푸터를 `slot="footer"`로 옮기기 — `section.page`와 혼용이 금지되어 있고, 옮기면 쪽 번호를 쓸 수 없다. 푸터는 각 `section.page` 안에 직접 넣는다
- `<doc-page>`의 `size="a4"`를 지우거나 바꾸기 — 이 값이 **화면 카드 크기와 인쇄 용지를 동시에** 정한다. `section.page` 구조에서는 `doc-page.js`가 이 값으로 `@page { size: 210mm 297mm }`를 주입하므로, 내보내기 대화상자 용지에 휘둘리지 않는다
- `<style>` 맨 위의 `@property --body-fs` / `--body-lh` 블록 삭제 — 속성 패널 값이 전달되지 않는 경로에서 본문이 16px·줄간 normal로 튀는 것을 막는다
- 링크 외 유채색 추가
- `▢` 사용 — 글리프가 없어 `□`로 폴백된다
- `position:fixed`·뷰포트 단위(`vh`/`vw`) — 인쇄에서 깨진다
- 색·크기 값을 인라인으로 새로 쓰기 — `var(--토큰)`을 쓴다

## 4. 산출

Claude Design에 등록해 편집·PDF 내보내기로 쓴다. 쪽 번호는 자동 생성되지 않으므로 푸터에 직접 적는다.

### 화면 = PDF

`<section class="page">` 하나가 A4 한 쪽이다. **편집 화면에 한 쪽이 카드 하나로 보이고, 그대로 인쇄된다.** 화면 카드 수 = PDF 쪽수이며, 내보내기 용지를 무엇으로 고르든 쪽수와 구성은 변하지 않는다(A4 판면이 그대로 유지된다).

**대신 한 쪽에 넘치면 다음 쪽으로 흘러가지 않고 잘린다**(`overflow:hidden`). 내용을 줄이라는 뜻이 아니라 쪽을 하나 더 만들라는 뜻이다. 잘렸는지는 편집 화면 카드에서 그대로 보이므로, 아래쪽이 잘려 보이면 `section`을 나눈다.

### 분량 — A4 인쇄 기준

세는 말은 **"쪽"으로 통일한다** — "장"·"페이지"를 섞어 쓰지 않는다.
`<section class="page">` 하나 = 편집 화면 카드 하나 = PDF 한 쪽 = A4 용지 한 장이고, 넷이 항상 1:1이다.

한 쪽의 본문 영역은 **973.7px(257.6mm)**이고, 기본값에서 들어가는 분량은 이렇다.

| 서식 | 본문 / 줄간 | 한 쪽 용량 | 95% 목표 |
|---|---|---|---|
| `report`·`brief` | 14px / 1.85 | 37.6줄 | **35.7줄** |
| `formal` | 13.5px / 1.75 | 41.2줄 | **39.2줄** |

원고를 부을 때 **쪽당 이 줄 수를 채운다.** "줄"은 본문 한 줄 높이로 환산한 값이며, h2 위아래 여백·요약밴드·표는 본문보다 자리를 더 먹는다.

**채움률은 자동으로 맞춰지지 않는다.** 지면은 고정된 A4 상자이고 남는 공간은 그대로 빈 여백이 된다. 다 쓴 뒤 반드시 재본다.

```bash
./sync/measure.sh 내문서.dc.html
```

| 채움률 | 할 일 |
|---|---|
| 100% 넘음 | 잘린다 — 쪽을 나누거나 속성 패널 값을 낮춘다 |
| 92~100% | 그대로 |
| 80~92% | 줄간을 올리거나 내용을 보탠다 |
| 80% 미만 | 뒤 쪽에서 당겨오거나 쪽을 합친다 |

세부 수치는 `STYLE.md` 참조. 어법·종결어미·문서 골격은 `doc-style` 스킬이 담당한다.
